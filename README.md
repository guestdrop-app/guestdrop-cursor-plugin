# GuestDrop Cursor plugin

Cursor Marketplace plugin for [GuestDrop](https://guestdrop.app): event photo-sharing QR codes from your assistant. The plugin lives in `plugins/guestdrop` and connects to the remote MCP server at `https://guestdrop.app/api/mcp` (OAuth sign-in).

Docs: https://guestdrop.app/mcp · Privacy: https://guestdrop.app/privacy · Support: support@guestdrop.app

Check the layout with `node scripts/validate-template.mjs`.
